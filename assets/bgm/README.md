# Background music

Drop **one** royalty-free looping track here, e.g. `stadium.mp3`.
Supported: `.mp3` `.ogg` `.wav`

Where to get it (free, no copyright claims):
- YouTube Studio -> Audio Library (filter: Ambient / Sports)
- Pixabay Music  -> https://pixabay.com/music/
- Free Music Archive (CC0 tracks)

Recommended: 2-4 minutes, soft stadium/crowd ambience, no vocals, ~-18 LUFS.
The overlay loops it automatically and ducks it to 20% whenever the Hindi
commentary or a sound effect plays.

If this folder is empty the engine synthesises a crowd-noise bed instead,
so you can rehearse before uploading anything.
