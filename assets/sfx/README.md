# Sound effects

Optional but strongly recommended. Filenames matter (lowercase, no extension):

| file             | plays when            |
|------------------|-----------------------|
| `six.mp3`        | a six is hit          |
| `four.mp3`       | a four is hit         |
| `wicket.mp3`     | a wicket falls        |
| `cheer.mp3`      | fallback crowd cheer  |
| `whistle.mp3`    | umpire/over cue       |
| `bat.mp3`        | bat-on-ball crack     |

Supported: `.mp3` `.wav` `.ogg`

Free sources: Pixabay Sounds, Freesound (CC0 filter), YouTube Audio Library.

Missing files are fine - the browser synthesises an equivalent sound with the
Web Audio API so nothing ever goes silent.
